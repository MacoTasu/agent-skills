# 変更ユニット (Change / Goal) — <タスク名>

> これは **変更ユニット(goal)**＝「今回これを変えるか」のデルタ。**製品仕様(anchor)ではない**。
> 製品仕様＝「機能が今どう振る舞うか」の現在の真実は各プロジェクトの `docs/specs/`。
> この goal で挙動を変えるなら、その PR で `product_spec` に挙げた `docs/specs/...` を新挙動に
> **reconcile(更新)** すること（agent のよりどころを腐らせない＝Specification Provenance）。詳細は
> `loop-intake-triage.md` の「0. 2層」。

> 立法 = 人間が書いて承認した正典(SSOT)。司法(`review-judge:judge`)はこれに照らして採点し、
> 自律ループ(`/loop-engine:loop-engine`)はこれを実装の目標として読む。
> 生成フロー: **人間がこのテンプレを `./goals/<slug>.md` にコピーして書く → PR →
> レビュー → main マージ ＝ 立法の承認 ＝ ループのトリガ**。
> 性質: spec(立法/SSOT)は **commit する**・**人間所有(ボットは書き換えない)**・更新は人間の spec PR。
> 派生(判定ログ `.claude/loop/judgments.md`・as-built `.claude/loop/runs/`)はボットが書く。
